## 🚀 Como Usar

### Desenvolvimento Local

**Terminal 1 - Frontend:**
```bash
cd herculano_pap
npm run dev
# Acesse: http://localhost:5173
```

**Terminal 2 - Backend (opcional):**
```bash
cd herculano_pap
node servidor.js
# Servidor em: http://localhost:3001
```

### Build para Produção

```bash
npm run build
# Gera: dist/
```

### Deploy Vercel

```bash
git add .
git commit -m "Design: Dashboard moderno dark mode"
git push origin main
```

Vercel vai deploy automaticamente! ✨
